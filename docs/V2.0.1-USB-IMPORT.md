# SHINO // TV HOME v2.0.1 — Import d'appairage HUB par clé USB

Cette modification est préparée **sur branche**, non compilée et non installée sur le Player.
Elle n'ajoute ni serveur ni accès direct à la partition USB : Android affiche un sélecteur
de documents (Storage Access Framework), qui propose les volumes fournis par le système.
La disponibilité d'un explorateur compatible sur le Player Pop réel est à vérifier.

## Sur le PC Windows

1. Brancher une clé USB sur le PC (volume, par exemple, `E:`).
2. Utiliser **uniquement** le fichier public `hub.owner-public.json` déjà livré avec
   SHINO RELAY 0.2 et la CA publique mentionnée par `caFile`.
3. Depuis la racine de ce dépôt, lancer :

```powershell
.\tools\New-TvHomeUsbPairing.ps1 `
    -PublicConfig 'C:\chemin\vers\SHINO-RELAY-0.2.0\hub.owner-public.json' `
    -OutputPath 'E:\SHINO-TV-HUB.json'
```

4. À l'invite masquée du PC, coller **le jeton lecteur TV_HOME existant**.
   Ce n'est **pas** le jeton LINK / PERISCOPE.
5. Éjecter proprement la clé USB.

Le script ne contacte aucun serveur : il lit le fichier public et la CA sur le PC.
Le JSON obtenu contient le **jeton TV_HOME en clair**. Ne pas le committer, le partager,
ni le stocker durablement sur une clé circulant entre appareils ; retirer le fichier
de la clé après l'import. Le secret sera chiffré par l'application Android lors de
l'enregistrement, exactement comme lors d'une saisie manuelle.

## Sur le Player Freebox Pop

1. Brancher la clé USB sur le **Player**, et non sur le Server Freebox.
2. Dans SHINO // TV HOME : **Réglages → SHINO HUB v2**.
3. Choisir **Importer configuration HUB depuis une clé USB (.json)**.
4. Dans le sélecteur Android, sélectionner `SHINO-TV-HUB.json` sur le volume USB.
   Si le premier sélecteur n'affiche pas la clé, essayer **Autre explorateur de fichiers**.
5. Confirmer le message d'import puis sélectionner **Enregistrer et revenir à l'accueil**.

L'import remplit localement l'adresse, le port, la CA publique, le pin et le jeton
lecteur. Aucune requête HUB n'est effectuée par l'import lui-même. L'appairage manuel
de la v2.0.0 est conservé.

**Si la clé n'est pas visible dans le sélecteur :** tester d'abord si VLC sur
le Player voit le volume (Free documente la navigation USB via VLC). Cela confirme
le montage, pas l'existence d'un fournisseur de documents Android pour JSON.
Une solution sans saisie TV est alors de copier le JSON dans le dossier
Téléchargements du Player avec un explorateur déjà installé, puis le sélectionner.
Ne pas promettre un accès USB brut par l'application.

## Format du fichier, v1

```json
{
  "format": "SHINO_TV_HOME_HUB_PAIRING",
  "version": 1,
  "host": "192.168.1.195",
  "port": 8767,
  "caPem": "-----BEGIN CERTIFICATE-----\n...\n-----END CERTIFICATE-----",
  "certificateSha256": "64 caractères hexadécimaux",
  "readerToken": "jeton-lecteur-TV_HOME"
}
```

Cet exemple est illustratif et non un fichier d'appairage fonctionnel.
Le parseur refuse un format/version incohérent, une adresse non privée,
un port invalide, un jeton hors format, une CA non valide et un pin mal formé ;
les contrôles TLS normaux s'appliquent ensuite à la connexion.

## Livraison restante

- Exécuter les tests `HubPairingImportTest`, tests UI de réglages, compilation APK et lint.

- Vérifier le stockage du jeton après `Enregistrer` et le retour à l'accueil.
