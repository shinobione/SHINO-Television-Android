## Comportement livré

Les réglages HUB v2 permettent de sélectionner un JSON par OpenDocument ou
GetContent, depuis la clé USB ou un autre emplacement proposé par Android.
Le fichier de 24 Ko maximum est lu via ContentResolver puis validé : objet unique,
format/version, types, IPv4 privée, port, jeton lecteur, CA et pin. Un BOM UTF-8
est accepté ; du contenu parasite après l'objet est refusé. Les deux sélecteurs
utilisent le même chemin d'import. L'annulation ne change pas le brouillon.

Les valeurs restent en mémoire jusqu'à **Enregistrer et revenir à l'accueil**.
L'import ne contacte pas le HUB et ne persiste pas le jeton ; l'enregistrement
réutilise le stockage AndroidKeyStore existant. Le script Windows produit un JSON
UTF-8 avec un jeton demandé au PC, sans appel réseau. Sa validation des plages
IPv4 privées correspond désormais à celle de l'application.

Les fonctions V2.0.0 sont conservées : lecture HUB HTTPS avec CA/SAN/pin, ancien
mode passerelle v1, PC/musique/Codex, fraîcheur et caches, horloge/météo,
applications et navigation D-pad. Aucun changement de manifeste, de permissions,
de launcher HOME, de notification listener ou d'identité de package.
